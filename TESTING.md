# Validation performed

Tested on October 1, 2026. These results describe this package, not a guarantee
for every game build or graphics driver.

## Automated tests

All **12 integration tests passed on both macOS and Ubuntu Linux**.

- macOS: Python 3, SPIRV-Tools 2025.3, LLVM 20.1.8.
- Lambda / Ubuntu: Python 3, SPIRV-Tools 2025.3 built from tag `v2025.3`
  (commit prefix `33e0256`), LLVM 14.0.0.

The tests cover:

1. Dry run preserves the source directory and writes no patches.
2. Apply changes exactly one byte and refuses an existing output directory.
3. Already-patched patterns are recognized without being rewritten.
4. Missing companion DXIL is refused.
5. DXIL/filename hash mismatch is refused.
6. Changed SPIR-V result IDs and instruction offsets are handled correctly.
7. An unexpected additional consumer of the sentinel is refused.
8. Multiple candidate conversions are refused as ambiguous.
9. An unknown hash is accepted when the identity/pattern checks pass.
10. No matching pattern returns a distinct nonzero status.
11. A malformed instruction length is refused.
12. A non-SPIR-V dump is reported and left untouched.

The changed-ID/offset tests assemble and validate transformed versions of an
actual shader. They preserve its SPIR-V version. The unknown-hash test changes
the DXIL container checksum field and recomputes the filename hash solely to
test the absence of an allowlist; it is not a valid new game build or a GPU test.

## Full dump

The script scanned **16,290 `.spv` files** from the existing AC8 dump on Lambda:

| Result | Count |
|---|---:|
| Recognized, validated and patched | 16 |
| Unrelated files ignored | 16,272 |
| Invalid headers reported and skipped | 2 |
| Refused candidate patterns | 0 |

All 16 generated replacements match the previously validated patches
byte-for-byte. Both originals and replacements pass `spirv-val --target-env
vulkan1.3`. A separate run on macOS produced the same 16 replacements.

The two damaged files were `3514fa13022bbf43.spv` and
`4970b0d26e4e01e9.spv`. Their contents were not repaired, copied to the output,
or treated as validated shaders. Their omission limits claims of complete
coverage of the original dump.

## GPU replay

The replacement generated by the Linux run for `e2ace7e3e8dbf87b` was tested
against the original in the same previously replayable Nsight capture.

| Run | Result |
|---|---|
| Original shader control | Exit 0; replay completed; one exact shader match; two successful presents |
| Patcher-generated replacement | Exit 0; replay completed; one exact shader match; two successful presents |

The control screenshot shows the cloud cutoff. The patched screenshot shows a
substantial cloud deck beneath the horizon and aircraft. The replacement was
injected by the existing process-local replay layer, which matches the original
shader bytes exactly. No new capture was needed.

Environment: RTX 4090, NVIDIA 580.159.03, Nsight Graphics 2025.5. The capture
originated from Proton Experimental 11.0-20260924, vkd3d-proton 3.1.0 build
`7f0c30ad3c8f28d`, Steam game build 25201480.

Only one shader variant was rendered in this replay comparison. The other 15
were statically validated and matched against earlier patch outputs; this is
not a visual test of all missions. Other GPU vendors, drivers, and game/Proton
versions have not been independently tested.

No game binaries or captured shader binaries are included in this package.
